# Ethics / dual-use note (Stage 1 draft)

Draft date: 15 October 2026. For the Organization Science Stage 1 package “Knowing When We Do Not Know.”

## Stage 1 prototype

- Tasks are constructed response profiles about interpersonal influence around a wrong leader recommendation. They are not field observations of named people or organizations.
- No human research participants are recruited, deceived, or observed in Stage 1. All model calls in the recorded pilot used institutional API access; no secrets are stored in the repository.
- Evaluator-only truth files are separated from public tasks so that reviewers can replay scoring without exposing the model to hidden labels during the loop.

## Risks and safeguards

- Dual-use concern is limited: the artifact teaches when not to claim a unique mechanism. It is not a toolkit for persuasion or covert influence.
- If Stage 2 adds a human-researcher comparison arm, that arm will require a separate ethics protocol (recruitment, consent, debrief, and data minimization) before any human data collection.
- Public release should keep redacted provider logs and avoid publishing institutional API keys, account identifiers, or non-public gateway configuration.
